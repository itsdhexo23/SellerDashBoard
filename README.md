# Seller Dashboard

A beginner-friendly React app for setting up a seller profile and managing a small product catalog in the browser.

## Features

- Seller onboarding with location and delivery details
- Add, edit, and delete products
- Custom product categories
- Browser Local Storage keeps seller and product data after refresh
- Responsive layout

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173/`.

## Built with

React, JavaScript, Vite, and CSS.
